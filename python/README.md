# Папка `python/` — портативний Python

Тут лежить портативний **Python 3.14** з усіма потрібними пакетами. `run.bat`
запускає застосунок саме цим Python, тож окремо встановлювати його на комп'ютер
школи не потрібно — усе вже всередині архіву.

## Пакети та версії

| Пакет | Версія | Навіщо |
|-------|--------|--------|
| Flask | 3.1.3 | веб-сервер, сторінки застосунку |
| ortools | 9.15.6755 | CP-SAT — ядро складання розкладу |
| pandas | 3.0.5 | залежність ortools (сам застосунок його не використовує) |
| numpy | 2.5.1 | залежність ortools |
| openpyxl | 3.1.5 | експорт розкладу в Excel |
| fpdf2 | 2.8.8 | експорт розкладу в PDF |

Точний перелік — у файлі [`data/requirements.txt`](../data/requirements.txt).
