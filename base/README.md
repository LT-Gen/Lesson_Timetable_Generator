# Папка `base/` — бази даних застосунку

Тут зберігаються бази даних. Усе в цій папці — дані вашої школи; вони лишаються
на вашому комп'ютері.

## Що тут з'являється

| Файл | Що це |
|------|-------|
| `school.db` | Реальна база вашої школи. Створюється автоматично при першому запуску `run.bat`. |
| `school-demo.db` | Демонстраційна база — навчальний приклад для ознайомлення. Іде вже готовою в архіві. Перемикання між нею та реальною — на сторінці «Налаштування школи». |
| `aktyvna_baza.txt` | Позначка з одним словом: `realna` або `demo` — яка база активна зараз. З'являється лише після натискання кнопки перемикання бази. Якщо файлу немає — активна реальна база. Зміна діє після перезапуску застосунку. |
| `school_v*.db` | Автоматична резервна копія перед оновленням структури бази — дані не втрачаються при переході на нову версію. |
| `school_avto_v*.db` | Щоденна автокопія при запуску застосунку. Зберігаються останні 7, старіші видаляються самі. У демо-режимі не створюється. |
| `pomylky.log` | Технічний опис непередбачених помилок. З'являється лише якщо збій стався; саме цей файл варто надіслати разом з описом проблеми. |
| `ostannya_migratsiya.json` | Службовий звіт «було → стало» після оновлення структури бази. Застосунок показує його одним банером і видаляє файл. |
| `onovlennya.json` | Коли востаннє перевірялась нова версія на GitHub і про яку вже показано банер. Даних школи не містить; якщо видалити — перевірка просто повториться. |

## Резервні копії вручну

Меню «Обслуговування → Резервні копії» дозволяє створювати, відновлювати,
імпортувати та видаляти копії бази — вони теж лежать у цій папці.
