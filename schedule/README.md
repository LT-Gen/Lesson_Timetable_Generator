# Папка `schedule/` — згенеровані розклади

Сюди застосунок зберігає готові файли розкладів:

- **`.xlsx`** — файл кожної генерації (сторінка «Генерація розкладу»): листи по
  класах, по вчителях і лист «Конфлікти» з нерозміщеними уроками;
- **`.pdf`** — розклад для друку: по класах, по вчителях, а також денний розклад
  усієї школи («Головна»).

Папка створюється автоматично при першому збереженні файлу. Її можна будь-коли
очистити — нічого важливого тут не зберігається, лише готові вивантаження.
