# Довідка LT-Gen — зміст

Інструкції по кожному розділу меню. У самому застосунку відкриваються кнопкою
**«?»** праворуч від заголовка сторінки. Тут — той самий текст у вигляді
`.md`-файлів (можна читати в блокноті).

Порядок роботи з новою школою приблизно такий: спершу **Налаштування школи** →
довідники (**Предмети**, **Класи**, **Вчителі**, **Кабінети**, за потреби
**Клас-комплекти** / **Асистенти** / **Групи**) → **Навчальний план** (і
**Позаурочний план**, якщо є) → **Генерація розкладу** → **Перегляд розкладу** /
PDF. **Резервні копії** — регулярно.
