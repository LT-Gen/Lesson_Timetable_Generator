# Класи

Довідник класів школи (паралель + літера). Кожен клас отримує навчальний план,
домашній кабінет і, за потреби, класного керівника.

## Що тут можна зробити

- **+ Додати клас** — паралель, літера (можна лишити порожньою, якщо клас єдиний
  на паралелі), кількість учнів (хлопці/дівчата рахуються в загальну суму),
  домашній кабінет, класний керівник.
- **Створити базові класи** — швидко додати по одному класу на кожну паралель
  вашого типу закладу (діапазон показано просто на кнопці: 1-11, 1-4 тощо).
- **Редагувати** / **Видалити** (з підтвердженням).
- Червоним підсвічено клас, не задіяний у навчальному плані; сірим — клас поза
  діапазоном поточного типу закладу.

## Підсторінка «Додатково»

- **Максимум уроків на день** — без фізкультури і окремо з фізкультурою. Вносьте з
  офіційного навчального плану МОН для цієї паралелі; типове значення — лише
  орієнтир.
- **Граничне** і **фактичне** навантаження (год/тиждень) — офіційні норми МОН.
  Генератор не розкладе план, що їх перевищує. Сіре число — типовий орієнтир, ще
  не задано вручну.
- **Мова навчання** — перевизначає типову мову школи для цього класу.

## Підсторінка «Доступність»

Сітка день × урок. Клік по клітинці робить слот **недоступним** (клас у цей час не
може мати урок — напр. плаваючий басейн, друга зміна частини класу). Клік по
заголовку дня/уроку перемикає весь рядок/стовпець, по кутовій клітинці — усю
сітку. Зберегти / Скасувати.

## Важливо

- Кожен клас повинен мати **унікальний домашній кабінет** — інакше два класи
  конфліктуватимуть за одне приміщення при генерації.
- Видалення класу прибирає його навчальний план, позаурочку, асистентів.
